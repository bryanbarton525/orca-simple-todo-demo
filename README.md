# README

## Vanilla Todo App

This is a minimal, single‑page todo application built with plain HTML, CSS, and vanilla JavaScript. No build tools or libraries are required.

### How to Run

1. Clone the repository or download the source files.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari).
3. You can start adding, completing, and deleting todos immediately.

### Features

- **Add Todo** – type a task in the input box and press *Add* or hit *Enter*.
- **Mark Complete** – click the task text to toggle a line‑through style.
- **Delete Todo** – click the red *✕* button to remove the task.

### No Dependencies

The app uses only native web APIs and does not rely on any external libraries or package managers.
